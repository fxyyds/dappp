# 电商数据实时处理系统 —— 数据契约文档

> 版本：v1.0（第一阶段：仅订单流）
> 适用范围：模拟数据生成器 → Kafka → Flink SQL → Doris 全链路

---

## 1. 订单事件消息格式（第一阶段）

### 1.1 Topic 定义

| Topic 名称 | 说明 | 分区数 | 保留策略 |
|-----------|------|--------|---------|
| `ec_order_events` | 订单事件流（下单/支付/取消/退款） | 3 | 7 天 |

### 1.2 消息格式（JSON，UTF-8）

```json
{
  "order_id": "ORD20260916235959123456",
  "user_id": 10086,
  "tenant_id": 1,
  "event_type": "CREATED",
  "product_id": 5001,
  "product_name": "无线蓝牙耳机",
  "category": "数码家电",
  "quantity": 2,
  "unit_price": 199.00,
  "total_amount": 398.00,
  "discount_amount": 30.00,
  "pay_amount": 368.00,
  "channel": "APP",
  "province": "上海市",
  "event_time": "2026-09-16 23:59:59",
  "process_time": "2026-09-16 23:59:59"
}
```

### 1.3 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| order_id | STRING | 是 | 订单号（格式：ORD + 时间戳 + 6位随机数） |
| user_id | BIGINT | 是 | 用户 ID |
| tenant_id | BIGINT | 是 | 租户 ID（多租户，1=默认租户，2=演示租户） |
| event_type | STRING | 是 | 事件类型，见枚举 |
| product_id | BIGINT | 是 | 商品 ID |
| product_name | STRING | 是 | 商品名称 |
| category | STRING | 是 | 商品类目（数码家电/服饰鞋包/食品生鲜/家居日用/美妆个护/运动户外） |
| quantity | INT | 是 | 购买数量 |
| unit_price | DECIMAL | 是 | 商品单价（元） |
| total_amount | DECIMAL | 是 | 订单原价合计 |
| discount_amount | DECIMAL | 是 | 优惠金额 |
| pay_amount | DECIMAL | 是 | 实付金额 |
| channel | STRING | 是 | 下单渠道：APP / WEB / MINI_PROGRAM |
| province | STRING | 是 | 收货省份 |
| event_time | TIMESTAMP | 是 | 事件发生时间（yyyy-MM-dd HH:mm:ss） |
| process_time | TIMESTAMP | 是 | 系统处理时间 |

### 1.4 event_type 枚举

| 值 | 说明 | 是否计入销售统计 |
|----|------|----------------|
| CREATED | 下单 | 否（仅记录） |
| PAID | 支付成功 | **是**（核心统计口径） |
| CANCELLED | 取消 | 否 |
| REFUNDED | 退款 | 否（单独统计退款额） |

> **统计口径约定**：销售实时分析以 `event_type = 'PAID'` 的 `pay_amount` 为准。

## 2. Doris 结果表设计（第一阶段）

### 2.1 销售实时聚合表（按分钟 + 租户 + 类目）

```sql
CREATE DATABASE IF NOT EXISTS ds_realtime;

-- 销售实时聚合表（Unique 模型，支持 upsert）
CREATE TABLE IF NOT EXISTS ds_realtime.sales_realtime_agg (
    stat_minute    DATETIME     COMMENT '统计分钟',
    tenant_id      BIGINT       COMMENT '租户 ID',
    category       VARCHAR(64)  COMMENT '商品类目',
    channel        VARCHAR(32)  COMMENT '下单渠道',
    province       VARCHAR(64)  COMMENT '省份',
    order_count    BIGINT       COMMENT '订单数（支付）',
    sale_amount    DECIMAL(18,2) COMMENT '销售额（实付合计）',
    product_count  BIGINT       COMMENT '商品件数'
)
UNIQUE KEY(stat_minute, tenant_id, category, channel, province)
DISTRIBUTED BY HASH(stat_minute) BUCKETS 4
PROPERTIES (
    "replication_num" = "1",
    "enable_unique_key_merge_on_write" = "true"
);

-- 销售明细表（支付订单明细，用于排行和钻取）
CREATE TABLE IF NOT EXISTS ds_realtime.sales_detail (
    order_id      VARCHAR(64)   COMMENT '订单号',
    tenant_id     BIGINT        COMMENT '租户 ID',
    user_id       BIGINT        COMMENT '用户 ID',
    product_id    BIGINT        COMMENT '商品 ID',
    product_name  VARCHAR(128)  COMMENT '商品名称',
    category      VARCHAR(64)   COMMENT '类目',
    quantity      INT           COMMENT '数量',
    pay_amount    DECIMAL(18,2) COMMENT '实付金额',
    channel       VARCHAR(32)   COMMENT '渠道',
    province      VARCHAR(64)   COMMENT '省份',
    event_time    DATETIME      COMMENT '事件时间',
    pay_minute    DATETIME      COMMENT '支付分钟（截断）'
)
UNIQUE KEY(order_id)
DISTRIBUTED BY HASH(order_id) BUCKETS 4
PROPERTIES (
    "replication_num" = "1",
    "enable_unique_key_merge_on_write" = "true"
);
```

## 3. Flink 作业输入输出约定

| 作业 | 输入 | 输出 |
|------|------|------|
| 销售实时聚合（sales-realtime） | Kafka `ec_order_events`（JSON，event_type=PAID） | Doris `ds_realtime.sales_realtime_agg` |
| 销售明细写入 | 同上 | Doris `ds_realtime.sales_detail` |

### 3.1 Kafka Source 参数

- bootstrap.servers: `kafka:19092`（Flink 容器内访问）
- group.id: `flink-sales-realtime`
- 起始位点: `latest-offset`（开发期），生产用 `earliest-offset`
- 时间语义: 使用 `event_time` 作为事件时间，watermark 允许 5 秒乱序

### 3.2 Doris Sink 参数

- fenodes: `doris:8030`
- jdbc 连接: `doris:9030`，root 用户，无密码（本地开发）
- 写入方式: Stream Load，`sink.properties.format=json`

## 4. 模拟数据生成器约定

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 事件速率 | 5 条/秒 | 可通过参数调整 |
| 租户分布 | 租户1: 70%，租户2: 30% | 验证多租户隔离 |
| 类目分布 | 6 个类目加权随机 | 数码家电 25%、服饰鞋包 20%、食品生鲜 20%、家居日用 15%、美妆个护 10%、运动户外 10% |
| 事件类型分布 | PAID 60%、CREATED 25%、CANCELLED 10%、REFUNDED 5% | |
| 金额范围 | 单价 20~5000 元，数量 1~5 | 正态偏态分布 |
| 省份 | 31 个省级行政区随机 | 加权：广东/浙江/上海/北京权重高 |
