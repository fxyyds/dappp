## M1 核心链路跑通

### M1 验收标准

1. 模拟订单数据生成器能按可配置速率持续向 Kafka 写入订单事件
2. Flink SQL「销售实时聚合」作业在 StreamPark 上运行，结果写入 Doris
3. 后端从 Doris 查询销售实时指标（金额/订单量/趋势）并通过接口返回
4. Vben 前端「销售实时分析大屏」出现秒级刷新的数字
5. StreamPark 支持双租户（两个 Team）管理
6. 本地 Git 已有核心代码提交记录
